# Design documents

The documents in this folder are written in **Turkish**: market research and competitor comparison
(`01-pazar-arastirmasi.md`), product vision and roadmap (`02-urun-ve-yol-haritasi.md`) and the choice of the
name (`03-isim-analizi.md`). The README, code and contributor docs are in English. Translations into English are
welcome; please open an issue first so two people do not translate the same file.

Also here: [`performance.md`](performance.md) (how panel-open time and memory are measured, with numbers) and
[`design/`](design/) (the 0.2 panel redesign: spec, plan and manual checklist, in English).
